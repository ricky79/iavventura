# Dialoghi più naturali — piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** gli otto personaggi delle tre avventure rispondono a saluti, congedi, ringraziamenti, scuse, «come state?», «chi siete?» e scortesie con testi d'autore nella loro voce; una domanda ripetuta non dà il testo identico; i gesti e le domande senza nome vanno all'ultimo personaggio con cui si è parlato; a Valdimora i personaggi hanno opinioni gli uni sugli altri; «chiedi a Livia di Corrado» non risponde più su Ettore.

**Architecture:** il gesto è un campo dell'azione «parla» (`Action.gesture`, enum `Gesture`), con i testi nei personaggi (`Character.gestures`, di tipo `Line`) e risposte neutre di riserva. Il motore ricorda i gesti e gli argomenti usati (`GameState.asked`) per scegliere `again`, e l'ultimo interlocutore (`GameState.last_speaker`). Il parser riconosce le formule brevi prima di ogni altro comando; l'interprete riceve i gesti nel campo `con` di «parla». I contenuti sono dati YAML.

**Tech Stack:** Python 3.12, Pydantic v2, pytest; Ollama con qwen2.5:3b per i test col modello vero.

**Spec:** `docs/superpowers/specs/2026-09-29-dialoghi-design.md`

## Decisioni prese nel piano

1. **`tests/prompt_rocca.txt` si aggiorna nel Task 5**, insieme al prompt, così la suite resta verde a ogni task; la verifica col modello vero arriva nel Task 8, e se il prompt cambiasse ancora il file si aggiorna di nuovo lì.
2. **Il pellegrino**: «chi sei?» e «come ti chiami?» passano dall'argomento `pellegrino` al gesto `chi_sei` (via gli alias `chi sei`, `chiami`, `nome`); l'argomento resta per il viaggio. I test che si aspettavano l'argomento si aggiornano (Task 7).
3. **Due minori della revisione dell'atto 1 che riguardano i dialoghi**, perché qui costano una riga: «ad Agnese» invece di «a Agnese» (Task 3, `articulated` con un nome proprio che comincia per «a»), il rifiuto di Ettore senza genere e la variante di Ferri quando Irene ha la grappa in mano (Task 6).
4. **Nelle frasi libere, solo il saluto** si trasforma nella domanda su un argomento che la frase nomina (come oggi); gli altri gesti restano gesti («grazie per la chiave» è un grazie). Per le formule del parser vedi la decisione 7.
5. **Le chiavi della memoria** (`GameState.asked`): `"<personaggio>:topic:<argomento>"` e `"<personaggio>:gesture:<gesto>"`, con `saluto` per il saluto.
6. **La memoria del dialogo non è la partita**: `asked` cambia solo quando il personaggio risponde con un suo testo, ma `last_speaker` cambia anche con un'azione rifiutata (una domanda a cui risponde `unknown`, un regalo che rifiuta: il giocatore gli ha comunque parlato). I test che controllano che un'azione rifiutata «non cambi niente» escludono `asked` e `last_speaker`, come già escludono `turns` (Task 2 e Task 3); la docstring di `engine.py` lo dice.
7. **Una formula che è il nome di un argomento** resta una domanda su quell'argomento anche nel parser (Task 4, con `find_topic`: parole esatte, come vuole il parser): prima del Task 7 il pellegrino ha ancora l'alias «chi sei» sull'argomento `pellegrino`. Se il nome dell'argomento è solo simile, decide l'LLM.
8. **«chiedi a X di Y» senza argomento** (Task 1): nel parser solo se nessun argomento di X è nominato, nemmeno per somiglianza («chiedi a Livia della chiave» resta all'LLM, che arriva all'argomento `chiavi`); nel gioco non contano le parole che stanno nei nomi dell'argomento scelto dal modello («chiave» è anche in «chiave dello scalone»).

## Review Focus

1. **Formule sociali che coincidono con comandi o con altro**: «dopo», «presto», «addio» da soli; «vai al diavolo» (comincia con un verbo di moto); «no, grazie» dopo una domanda di conferma, anche con un personaggio presente. Devono fare la cosa giusta — test nel Task 4 (`test_social_formulas_do_not_steal_commands`, `test_no_thanks_answers_the_question_even_with_someone_here`).
2. **Il gesto a chi, con più personaggi e nessun nome**: col solo ultimo interlocutore presente; con l'ultimo interlocutore assente; senza ultimo interlocutore — test nel Task 3 (motore, «dai»), nel Task 4 (`test_a_gesture_without_a_name_goes_to_the_last_one_spoken_to`, `test_giving_to_someone_elsewhere_gives_nothing_to_the_last_one_spoken_to`) e nel Task 5 (`test_with_two_here_nobody_named_is_the_last_one_spoken_to`).
3. **Frasi con un argomento e un gesto insieme** («mi dispiace per la contessa», «grazie per la chiave», «come va?» quando «come va» è un argomento) — test nel Task 4 (`test_a_formula_that_is_a_topic_is_a_question`), nel Task 5 (`test_thanks_naming_a_topic_are_still_thanks`) e col modello vero nel Task 8.
4. **Salvataggi di prima** senza `asked` e `last_speaker`, e un `last_speaker` che il mondo non ha più — test nel Task 2 e nel Task 3.
5. **Il dottore addormentato** con i gesti nuovi e gli argomenti nuovi: russa e basta — test nel Task 6.

    def _names_something_else(self, person: Character, topic: Topic, words: list[str]) -> bool:
        """Whether the words name another character or an item of the world, by words that are not in
        the names of the topic ("chiave" is also in «chiave dello scalone»)."""
        topic_words = {word for name in (topic.name, *topic.aliases) for word in significant_words(name)}
        others = [character for character in self.world.characters.values() if character.id != person.id]
        return any(
            not set(name) & topic_words
            for thing in [*others, *self.world.items.values()]
            for name in names_said(thing, words)
        )
```

def _said(state: GameState, key: str, variants: tuple[TextVariant, ...], text: str, again: str | None) -> str:
    """What a character says: the first variant that holds; else, from the second time on, `again` if
    there is one; else the text. From now on it counts as said."""
    line = _first_variant(variants, again if again is not None and key in state.asked else text, state)
    state.asked.add(key)
    return line

def _addressee(
    characters: Sequence[tuple[Character, Sequence[Topic]]], last_speaker: str | None
) -> tuple[Character, Sequence[Topic]] | None:
    """Who a sentence without a name is for: the only one here, or the one spoken to last if here."""
    if len(characters) == 1:
        return characters[0]
    return next((pair for pair in characters if pair[0].id == last_speaker), None)


def _gesture(
    words: list[str], characters: Sequence[tuple[Character, Sequence[Topic]]], last_speaker: str | None
) -> Action | None:
    """«grazie», «arrivederci, Livia», «Livia, come state?»: a gesture, if the words are a formula with
    at most the name of someone here at the start or at the end."""
    said = tuple(word for word in words if word not in STOPWORDS)
    for person, topics in characters:
        for phrase in {significant_words(name) for name in (person.name, *person.aliases)} - {()}:
            size = len(phrase)
            for rest in (said[size:] if said[:size] == phrase else None, said[:-size] if said[-size:] == phrase else None):
                if rest is not None and rest in GESTURE_FORMULAS:
                    return _said_to(person, topics, rest)
    if said not in GESTURE_FORMULAS or (addressee := _addressee(characters, last_speaker)) is None:
        return None
    return _said_to(*addressee, said)


def _said_to(person: Character, topics: Sequence[Topic], formula: tuple[str, ...]) -> Action:
    """The gesture of a formula; the question, if the formula is the name of one of the character's
    topics (the pilgrim's «chi sei»)."""
    topic = find_topic(formula, topics)
    if topic is not None:
        return Action(verb=Conversation.ASK, target=person.id, topic=topic.id)
    return Action(verb=Conversation.TALK, target=person.id, gesture=GESTURE_FORMULAS[formula])

def describe(action: Action) -> str:
    """The action with ids, as the engine receives it: "usa corda_con_gancio con pozzo", "chiedi pellegrino
    di torre", "parla livia: grazie"."""
    words = [
        action.verb,
        action.direction or action.target or "",
        f"con {action.with_}" if action.with_ else "",
        f"di {action.topic}" if action.topic else "",
    ]
    described = " ".join(word for word in words if word)
    return f"{described}: {action.gesture}" if action.gesture else described
```

  > - **I gesti**: oltre al saluto, il personaggio risponde a congedi, ringraziamenti, scuse, «come stai?», «chi sei?» e scortesie con i testi di `gestures`. Le formule brevi («grazie», «arrivederci, Livia», «come state?») le capisce il parser; le frasi più libere l'interprete, col verbo «parla» e il gesto nel campo `con`. Un gesto senza testo riceve una risposta neutra col nome del personaggio («Livia annuisce.»); «chi sei?» senza testo risponde `unknown`. Una formula che è proprio il nome o un alias di un argomento resta la domanda su quell'argomento; tra le frasi libere, solo il saluto che nomina un argomento diventa la domanda su quell'argomento («grazie per la chiave» è un grazie).
